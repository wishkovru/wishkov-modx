# Вишков: дополнение MODX с кнопкой «В вишлист»

Посетитель нажал «В вишлист», и страница сохранилась в его вишлисте на Вишкове. Одна HTML-ссылка, без скриптов на вашем сайте.
Кнопка это обычная ссылка на [wishkov.ru](https://wishkov.ru): до нажатия с вашего сайта на наш сервер не
уходит ничего, ни запросов, ни скриптов, ни счётчиков.

Версия: 1.0.0

## Как установить

1. Скачайте `wishkovbutton-1.0.0-pl.transport.zip` из раздела Releases этого репозитория.
2. В админке MODX: «Пакеты → Установщик» (Extras → Installer), кнопка «Загрузить пакеты» со стрелкой,
   пункт «Загрузить пакет с компьютера» (Upload a package), выберите zip; в строке пакета «Установить» (Install),
   затем «Продолжить».

Проверено на MODX Revolution 3.2.4-pl (PHP 8.2); версии 3.0 и 3.1 не проверялись. Пакет собран на MODX 3
и на MODX 2.8 не ставится: в нём классы MODX 3 с пространствами имён, которых в 2.8 нет (установщик отвечает «Невозможно установить пакет с подписью: wishkovbutton-1.0.0-pl»).

Пакет собирается самим MODX (`_build/build.transport.php`, запуск внутри установленного MODX), исходники и сборка
лежат в папке `wishkovbutton/` этого репозитория.

## Как пользоваться

Вставьте вызов сниппета в шаблон или в содержимое ресурса:

```
[[WishkovButton]]
[[!WishkovButton? &theme=`outline`]]
```

Кнопка ведёт на адрес текущей страницы и передаёт её заголовок (`pagetitle`) как название желания.
Если сниппет вызван без ресурса, он ничего не выводит. Вызов с `!` не кэшируется.

Перед удалением пакета уберите вызовы `[[WishkovButton]]` из шаблонов и ресурсов: страница после удаления
открывается, на месте кнопки пусто, но MODX пишет в журнал ошибок «Could not find snippet with name WishkovButton».

### Параметры сниппета

| Параметр | Значения | Что значит пусто |
|---|---|---|
| `&theme` | `fill`, `outline`, `soft` | берётся системная настройка |
| `&size` | `m`, `s` | берётся системная настройка |
| `&label` | до 60 знаков | берётся системная настройка |
| `&iconOnly` | `1` или `0` | берётся системная настройка |
| `&margin` | 0 до 40 (px) | берётся системная настройка |
| `&url` | адрес `http://` или `https://` вместо адреса страницы | адрес текущего ресурса; с `&url` заголовок страницы не передаётся |
| `&ref` | метка источника | `modx` |

## Системные настройки

«Система → Системные настройки», пространство имён `wishkovbutton`. Они действуют, когда параметр сниппета не задан.

| Настройка | Значения | По умолчанию |
|---|---|---|
| `wishkovbutton.theme` | `fill` (фиолетовая заливка), `outline` (контурная), `soft` (мягкая сиреневая) | `fill` |
| `wishkovbutton.size` | `m` (средний), `s` (малый) | `m` |
| `wishkovbutton.label` | до 60 знаков | «В вишлист» |
| `wishkovbutton.icon_only` | да / нет | нет |
| `wishkovbutton.margin` | 0 до 40 px | 8 |

## Проверено на

- MODX Revolution 3.2.4-pl (PHP 8.2.35, MariaDB 11): загрузка zip и установка через «Установщик», сниппет и пять
  системных настроек с подписями на русском, две кнопки на ресурсе (`[[WishkovButton]]` и
  ``[[!WishkovButton? &theme=`soft` &size=`s`]]``), адрес кнопки с `ref=modx` и заголовком ресурса, смена
  `wishkovbutton.theme` в системных настройках меняет кнопку без параметров сразу после сохранения, переустановка
  сохраняет изменённые настройки, «Деинсталлировать» (страница открывается, на месте кнопки пусто, ошибок PHP нет).
- MODX Revolution 2.8.8-pl (PHP 8.2.35): установка, обе кнопки на ресурсе, смена дизайна и удаление работают, если
  пакет собран на самом MODX 2.8 из тех же исходников; пакет, собранный на MODX 3, на 2.8 не ставится.

## О сервисе Вишков

Вишков ([wishkov.ru](https://wishkov.ru)) это бесплатный российский сервис, где люди ведут вишлисты: записывают желания,
дают близким одну ссылку, и те бронируют подарки так, что никто не покупает одно и то же. Дополнение для MODX сделала та же
команда, что делает сервис, поэтому кнопка и страница добавления на wishkov.ru развиваются вместе.

За сервисом стоит маленькая независимая команда без инвесторов: идея появилась за праздничным столом, где друзья
скидывались «на что-нибудь», а родственники дарили дубли. Сервер в России, персональные данные обрабатываются по 152-ФЗ,
в поддержке отвечаем в течение дня.

## Преимущества перед другими сервисами

- Бесплатно без оговорок: тарифов, платных функций, привязки карты и смс нет.
- Друзьям владельца не нужен аккаунт: ссылка открылась, подарок забронирован.
- Достаточно ссылки на товар: название, цену и фото сервис заполнит сам, и не только для маркетплейсов.
- Полминуты на вишлист, с телефона или с компьютера, без лишних экранов.
- Режим «сюрприз» скрывает брони от того, кому дарят.
- Антивишлист: отдельный список «пожалуйста, не это», чтобы гостям не было неловко.
- Двадцать одна тема оформления и свои фото: вишлист похож на праздник, а не на таблицу.
- Готовая сторис для соцсетей за один тап: дата, отсчёт до праздника и подарки на одной картинке.
- Друзья, напоминания о днях рождения, вишлисты на двоих или на всю семью.
- Желание не обязано быть товаром: поход в горы или урок керамики вносятся вручную за минуту.
- Каталог «Идеи подарков» по поводам, интересам и бюджету, когда своих идей нет.
- Сниппет выводит одну ссылку: на вашем сайте нет ни наших скриптов, ни трекеров.

## English

Wishkov Button adds the `[[WishkovButton]]` snippet to MODX Revolution: a plain "В вишлист" (add to wishlist) link
that saves the current page to the visitor's wishlist on wishkov.ru. No scripts, no tracking, no requests from your
site until the click.

Install: Extras, Installer, Upload Package, pick `wishkovbutton-1.0.0-pl.transport.zip`, Install.
Tested on MODX Revolution 3.2.4-pl (PHP 8.2); 3.0 and 3.1 were not tested. The package is built on MODX 3 and does not
install on MODX 2.8: it uses MODX 3 namespaced classes that 2.8 lacks (a package built on 2.8.8 from the same sources works there).
Use: `[[WishkovButton]]` or `[[!WishkovButton? &theme=`outline`]]`. Snippet properties: `theme`, `size`, `label`,
`iconOnly`, `margin`, `url`, `ref`. Defaults live in System Settings, namespace `wishkovbutton`.
